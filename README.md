# 紡ぐ — 顧客管理

ログイン、顧客一覧、名前・ランク検索、顧客ランク、顧客詳細、顧客ごとのメモ追加を備えた、依存関係なしのフロントエンドデモです。

## 起動方法

`index.html` をブラウザで直接開くか、任意の静的ファイルサーバーで配信してください。

```bash
python3 -m http.server 8000
```

ブラウザで `http://localhost:8000` を開きます。追加したメモはブラウザの `localStorage` に保存されます。

## ログイン

次のデモアカウントを使用します。

- メールアドレス: `admin@tsumugu.jp`
- パスワード: `customer2026`

ログイン状態は同じタブの `sessionStorage` に保存され、ログアウトすると破棄されます。

> [!IMPORTANT]
> この認証は、バックエンドを持たない静的デモ用の画面保護です。認証情報はフロントエンドに含まれるため、本番環境では利用できません。本番運用では、サーバー側でパスワードを安全に検証し、適切なセッション管理とアクセス制御を実装してください。
